# Satmi Orders

Private dark-mode operations dashboard for the Satmi `Shopify_5` channel in Shiprocket.

## What it does

- Full initial Shiprocket order import into D1
- Authenticated real-time webhook receiver
- Daily API reconciliation at 00:00 IST
- Status tabs for New, Ready to ship, Shipped, Delivered, RTO, and All
- Search plus payment, courier, pickup-location, and date filters
- Private ChatGPT sign-in for the dashboard and manual sync endpoint

Runtime secrets are configured in Sites and are never included in source control.
